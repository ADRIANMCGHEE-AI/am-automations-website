# Website measurement

The site emits `am:measurement` browser events for Project Viewed, Demo Opened, Enquiry Started, Email Clicked, WhatsApp Clicked and confirmed Email Copied.
Only an allowlisted interest identifier and pathname are included; message contents, email drafts and free text are not collected.
If an owner-configured Plausible integration defines window.plausible, the same custom events are forwarded. The site does not create an account, load a tracking script or send analytics requests on its own. Configure the provider, corresponding event goals and privacy notice before enabling collection. Do not count email or WhatsApp clicks as received enquiries.
Search Console: verify adrianmcgheeautomations.com with the owner's Google account, inspect the main pages and submit /sitemap.xml.
The preferred canonical host is adrianmcgheeautomations.com. A permanent www redirect must be configured at the hosting/domain layer; Next static export cannot enforce host redirects.
A professional founder portrait can be added when an approved image is supplied. No fabricated portrait or unsupported client results have been added.
