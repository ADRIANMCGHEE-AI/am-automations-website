# Website data and settings

All editable copy, services, project configuration, logos, fonts and saved preview images are included.
The website has no server-side contact-form inbox, customer database or enabled analytics provider.
Email and WhatsApp links open drafts in the visitor's chosen app.
Theme preference (`am-theme`) is stored in each visitor's browser and will not transfer to a different origin.
Measurement hooks exist but do not imply an analytics account is configured.
`source/.env.example` contains the public site URL; no secret is required to run this version.

Northstone and Automated Follow-Ups are external demos linked by this website.
Their application source is not contained in this website export.
Do not add LLK or Cheshire Gas to the public AM Automations portfolio without fresh permission.
